Cláusula 2

POLÍTICA DE PRIVACIDADE

Zero-Tracking · Zero-Cookies · FADP/LPD · RGPD

Dados Recolhidos

Este website não recolhe, processa, armazena nem transmite quaisquer dados pessoais a servidores externos. Não existem cookies de rastreamento, pixels de análise, scripts de terceiros ou formulários que transmitam dados para servidores remotos. O único estado persistido é a preferência de idioma (localStorage('vc-locale')) e a preferência de instalação (localStorage('a2hs-dismissed')), armazenados exclusivamente no dispositivo do utilizador.

localStorage — Dados no Dispositivo

  • vc-locale — Preferência de idioma (ex: "pt-PT"). Nunca transmitido.
  • vc-cookie — Preferência de consentimento de cookies (0 ou 1).
  • a2hs-dismissed — Preferência de instalação PWA. Nunca transmitido.

Contacto por Email

Se nos contactar via email (edumonteiro.dev@gmail.com), os dados fornecidos (nome, email, mensagem) serão utilizados exclusivamente para responder ao pedido e não serão partilhados com terceiros, nem utilizados para fins comerciais não solicitados.

Direitos do Titular dos Dados (RGPD Art. 15-22 / FADP)

  • Acesso — Direito a saber quais os dados processados.
  • Rectificação — Direito a corrigir dados incorrectos.
  • Eliminação — Direito ao apagamento ("direito ao esquecimento").
  • Portabilidade — Direito a receber dados em formato estruturado.
  • Oposição — Direito a opor-se ao tratamento para fins de marketing.

Para exercer estes direitos: edumonteiro.dev@gmail.com

Cláusula 5

POLÍTICA DE COOKIES — PADRÃO ZERO-TRACKING

Zero Cookies de Terceiros · Zero Analytics · Zero Rastreamento

Declaração de Zero-Tracking

Este website opera segundo um padrão de Zero-Tracking. Não são utilizados quaisquer cookies de rastreamento, cookies de sessão de terceiros, pixels de análise (Google Analytics, Facebook Pixel, LinkedIn Insight, etc.), scripts de marketing ou tecnologias de fingerprinting. O website não rastreia o comportamento de navegação do utilizador.

localStorage — Armazenamento Local Funcional

Tecnicamente, este website utiliza localStorage (armazenamento local do browser) — não cookies HTTP — para persistir preferências funcionais estritamente necessárias:

  • vc-locale — Idioma seleccionado pelo utilizador. Base legal: interesse legítimo / funcionamento essencial.
  • vc-cookie — Decisão do utilizador sobre o banner informativo. Base legal: consentimento.
  • a2hs-dismissed — Decisão sobre o modal de instalação PWA. Base legal: interesse legítimo.

Estes dados são puramente locais: residem no dispositivo do utilizador, nunca são transmitidos, e podem ser apagados a qualquer momento limpando os dados do browser.

Cookies de Infraestrutura (GitHub Pages)

O hosting via GitHub Pages pode definir cookies técnicos de infra-estrutura da Microsoft/GitHub, fora do controlo do responsável deste website. Consulte a política de privacidade do GitHub para detalhes. Não são cookies de rastreamento de comportamento.

Gestão e Eliminação

O utilizador pode eliminar todos os dados de localStorage a qualquer momento: Definições do Browser → Privacidade → Limpar dados de navegação → Dados de sites. Após eliminação, as preferências regressam ao estado inicial na próxima visita.

Ausência de Consentimento para Rastreamento

Dado que não existem cookies de rastreamento ou análise, não é necessário obter consentimento adicional para a sua colocação (conforme Directiva ePrivacy e RGPD). O banner informativo apresentado é uma medida de transparência voluntária, não uma exigência legal neste contexto específico.
