Política de Privacidade

Vigência: 16 de Agosto de 2026 · Lei aplicável: RGPD (UE 2016/679) + FADP/LPD (Suíça) · monteiro.is-a.dev

1. Minimização de Dados

Esta infraestrutura opera sob arquitectura Zero Trust e total adesão ao RGPD (UE) e FADP/LPD (Suíça). Apenas recolhemos os metadados técnicos estritamente necessários para o funcionamento offline (PWA) e os dados submetidos voluntariamente nos formulários de contacto via Web3Forms para estabelecer comunicações B2B.

Não existem cookies de rastreio, publicidade ou analítica de terceiros. O único armazenamento local utilizado é o localStorage para preferência de idioma (vc-locale) e consentimento de cookie (vc-cookie-choice) — ambos purguéis a qualquer momento.

2. Tratamento e Segurança

Todo o tráfego é forçado a HTTPS via HSTS (max-age 2 anos + preload). O CSP (Content Security Policy) bloqueia activamente exfiltrações não autorizadas. Nenhum dado pessoal é transferido para fora do contexto da comunicação B2B iniciada pelo próprio utilizador.

A aplicação PWA utiliza a Cache API do Service Worker exclusivamente para disponibilidade offline dos ficheiros estáticos — sem qualquer dado pessoal em cache.

3. Direitos dos Titulares (RGPD Art. 15–22 / FADP)

Como utilizador ou entidade detém os seguintes direitos, exercíveis sem custo:

Acesso · Rectificação · Eliminação ("direito ao esquecimento") · Limitação do tratamento · Portabilidade · Oposição

Qualquer pedido formalizado será processado tecnicamente e legalmente no prazo de 48 horas. Em caso de violação de dados, notificação à autoridade competente no prazo máximo de 72 horas (conforme Art. 33 RGPD).

Encarregado da Protecção de Dados (DPO): edumonteiro.dev@gmail.com

4. Transferências Internacionais

Os dados submetidos via Web3Forms são processados nos termos das suas políticas de privacidade (UE/EEA). Não existem outras transferências de dados para países terceiros. O presente site é servido via Vercel/Netlify com CDN Edge — as políticas de adequação de dados da UE aplicam-se.

5. Contacto e Autoridade de Supervisão

Para exercício de direitos ou reclamações: edumonteiro.dev@gmail.com
